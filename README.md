# ERP/YMS ЖБИ — интерактивный прототип

Прототип единой цифровой платформы для завода железобетонных изделий (ЖБИ):
CRM с IP-телефонией, складской учёт с резервом, производство по спецификациям (BOM),
управление двором и КПП (ANPR), документооборот, аналитика, роли и аудит.

**Демо:** https://ulankn8.github.io/erp-jbi-prototype/

## Что внутри

- **Сводка и Аналитика** — KPI, графики выпуска, воронка продаж, умные подсказки по данным.
- **Продажи (CRM)** — канбан сделок, всплывающая карточка входящего звонка (Linkus), создание накладной из сделки.
- **Склад** — сырьё (обеспеченность по сменам), готовая продукция по зонам и по изделиям, резерв под накладные.
- **Документы** — приходные (ПН), расходные (РН), отчёты производства (ОП): просмотр, печать, скачивание (HTML/CSV).
- **Производство** — калькулятор потребности по спецификации, отчёт за смену с фоновым списанием сырья.
- **Двор и КПП** — распознавание номеров (ANPR), логика шлагбаума по активной накладной, архив рейсов.
- **Роли (RBAC)** — администратор, менеджер, мастер цеха, кладовщик, оператор КПП.
- **Журнал действий** — аудит операций; **Интеграция 1С** — выгрузка документов и импорт оплат.
- Двуязычный интерфейс (РУС/КЫР), светлая и тёмная темы.

## Технически

Это статический прототип на одном HTML-файле (без бэкенда). Все данные живут в памяти
страницы — можно свободно кликать, «проводить» документы и наблюдать сквозную логику.
Открывается двойным кликом по `index.html` или по ссылке демо выше.
