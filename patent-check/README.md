# Патент Чек 1.0

Публичный интерактивный прототип: https://ulankn8.github.io/erp-jbi-prototype/patent-check/

Один самодостаточный `index.html` с концепцией, приложением заведения, кабинетом Кыргызпатента, публичной картой и каталогом произведений.

Данные, распознавание и оплата — демонстрационные. Загруженные плейлисты и изменения сохраняются в браузере. Скачиваемые WAV-файлы — синтезированные образцы, не записи артистов.
